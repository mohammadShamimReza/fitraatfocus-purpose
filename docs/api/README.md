# API Documentation System (fitraatfocustodotemplate)

Professional API + schema + model map for Cloud Function `studio`.

Source of truth:

- Routes: `functions/src/routes/*.ts`
- Controllers: `functions/src/controllers/*.ts`
- Services: `functions/src/services/*.ts`
- Validators: `functions/src/validators/*.ts` (Zod)
- Models/types: `functions/src/models/*.ts`

Use `api-map.md` as entry point, then endpoint docs, schema docs, and model docs.
